# Город искусств · Новогодняя ночь

Наведите камеру на постер «Город искусств». С наступлением ночи зажигаются фонари, у клумб и на набережной появляются сугробы, а на площади вырастают заснеженные ёлки. Примерно на 9-й секунде центральный куб даёт импульс, и по площади расходятся мягкие световые волны. Следом зажигаются гирлянды на ёлках, а на восьми открытых площадках по очереди включаются рампы и движущиеся софиты. Примерно на 17-й секунде над крышами начинается салют. После финала на постере остаётся зимний город с праздничным освещением.

- `index.html` — страница WebAR и просмотр анимации без камеры.
- `3_g.png` — исходное вложение, 1087 × 1447 пикселей.
- `targets.mind` — маркер MindAR 1.2.5 для этого постера.
- `winter-scenery.webp` — изображения заснеженных елей и сугробов с прозрачным фоном.

## Публикация на GitHub Pages

Файлы пилота размещаются в папке `city-arts-ar/` ветки `main` репозитория `temaiavdoshin-byte/new-year-ar`. GitHub Pages публикует папку по адресу [открыть пилот](https://temaiavdoshin-byte.github.io/new-year-ar/city-arts-ar/).

Для обновления замените нужные файлы внутри `city-arts-ar/` и дождитесь завершения публикации в **Actions**. Сохраните регистр букв и расширения. Если разворачиваете копию отдельно, загрузите четыре файла пилота в корень ветки `main` и в **Settings → Pages** выберите **Deploy from a branch → main → / (root)**.

[Инструкция GitHub по настройке источника публикации](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Проверка на iPhone

1. Откройте HTTPS-адрес непосредственно в Safari. Нажмите **Включить камеру** и разрешите доступ.
2. Наведите заднюю камеру на весь распечатанный постер или на `3_g.png`, открытый на другом экране. Избегайте бликов и держите в кадре края изображения.
3. Проверьте, что подсветка совпадает с окнами и двумя кубами при небольшом наклоне телефона. Затемнение выходит за все четыре края постера и плавно сходит на нет за периметром.
4. Дождитесь салюта над крышами. Кнопка **Повторить** запускает цикл снова. Если убрать постер из кадра, эффекты плавно погаснут. При потере постера меньше чем на 3 секунды сцена плавно появится и продолжится с места паузы. После 3 секунд или дольше сцена начнётся с наступления ночи.

Кнопка **Смотреть без камеры** позволяет проверить постановку эффектов прямо на исходном постере. Этот режим работает и при локальном открытии `index.html`, если `3_g.png` и `winter-scenery.webp` лежат рядом. Для AR на iPhone нужны HTTPS и доступ к интернету для загрузки A-Frame 1.6.0 и MindAR 1.2.5.
